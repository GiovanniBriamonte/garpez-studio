# garpez.tv

The Garpez website (garpez.studio): a CRT television you zap through. It is a Next.js project; the home page is the television. The TV is a Blender scene rendered in layers; the page puts the layers back together in the browser and draws the channels, the tube effect, the power-on/off animation and the sounds live in code.

## Folders

| Folder | What's in it |
|---|---|
| `public/tv/` | **The television page, built.** Static files served by Next.js at `/` (the rewrite in `next.config.ts`). Don't edit them by hand: they are regenerated by `tools/build_site.py`. |
| `app/` | Next.js. Today it only has the root layout; add real Next.js pages here (e.g. `/work`, `/about`) when you need them. |
| `src/` | The page **sources**: `template.html` (layout, CSS, all the JavaScript), `audio.js` (synthesised sounds), `screensaver-sprite.svg` (the ladybird). |
| `tools/` | `build_site.py` turns `src/` + `renders/` into `public/tv/`. `fix_floor.py` evens out a dark band on the studio floor in the base render. |
| `blender/` | The 3D scene: `garpez_tv.blend` (open it in Blender 4.x), `build_scene.py` (builds the whole scene from code), `make_textures.py`, `render_passes.py` (renders the layers the site needs), `assets/` (logo SVG, scratch textures). |
| `renders/` | The rendered layers (4K PNG) the site is built from. Keep them: rebuilding the site needs them, re-rendering them takes about an hour. |

## Editing the website (the usual case)

Edit **`src/template.html`**, never `public/tv/index.html` (it is overwritten on every build). Then:

```bash
npm install                              # once
python3 -m pip install pillow numpy      # once
python3 tools/build_site.py              # rebuilds public/tv/
npm run dev                              # open http://localhost:3000
```

Where things live in `src/template.html`:

- **Channels:** the `const CH = [...]` list. Each entry is a name plus a draw function.
  - `ident` is the GARPEZ.TV carousel: words and colours in `const WORDS`, timing in `BEAT`.
  - `screensaver` is the ladybird.
  - `noSignal` is the NO SIGNAL channel.
  - The INFO channel's text is plain HTML in `<div class="infoch" id="info">`.
- **Video channels:** add an `.mp4` to `public/tv/`, a `<video id="v_name" src="name.mp4" muted loop playsinline>` next to `v_work`, and an entry `{ name: 'NAME', draw: videoChannel($('v_name')), video: $('v_name') }`. Keep clips short and compressed: the screen is only 400 px wide.
- **Tube effect** (curvature, glow, colour fringing, scanlines): the WebGL shader in the `TUBE EFFECT` section. The constants `CURVE_X`, `CURVE_Y`, `FRINGE` and `GLOW` sit at its top.
- **Bottom chroma band:** the `headSwitch` function. Opacity is the `a = ((.08 + ...` line; the irregularity comes from `wave` and `segs`.
- **Channel change:** `startTransition` and the warp in `frame()`.
- **Power on/off:** `tubeState`.
- **Sounds:** `src/audio.js`. They are synthesised; swap them for real samples when you have them.

## Changing the TV itself (Blender)

The scene is generated by `blender/build_scene.py`, so make changes there, not by hand in the `.blend`, or the next rebuild will lose them. Full pipeline:

```bash
cd blender
python3 make_textures.py                                   # label + softbox textures -> blender/build/tex
blender -b -P build_scene.py -- preview                    # rebuilds garpez_tv.blend

# render the layers (from blender/; 3840x2160 except spill)
blender -b -P render_passes.py -- mask  3840 2160 ../renders/mask.png
blender -b -P render_passes.py -- keys  3840 2160 ../renders/keys.png
blender -b -P render_passes.py -- spill 1920 1080 ../renders/spill.png
blender -b -P render_passes.py -- dark  3840 2160 ../renders/dark.png
blender -b -P render_passes.py -- base  3840 2160 ../renders/base_raw.png

cd ..
python3 tools/fix_floor.py      # renders/base_raw.png -> renders/base.png
python3 tools/build_site.py     # -> public/tv/
```

The passes:

| Pass | What it renders |
|---|---|
| `base` | The whole TV with the screen off. |
| `dark` | The area around the screen with the tube black. |
| `keys` | All four keys pressed down. |
| `mask` | The exact shape of the picture area. |
| `spill` | Only the light the tube throws on the set. |

On an Apple Silicon Mac, renders are much faster on the GPU: in Blender go to Preferences → System → Cycles Render Devices → Metal, then add `s.cycles.device = 'GPU'` near the top of `render_passes.py`.

If you only change something small and local (as we did for the speaker grille), you can render just that region and blend it into `renders/base_raw.png` instead of re-rendering everything.

## Deploying

Import the repository on Vercel: it is a standard Next.js project, no settings needed. The television's files are served from `public/tv/`; the page has `<base href="/tv/">`, so its relative paths work while the address bar shows `/`.

## Notes

- **Fonts:** Archivo Black, VT323, Doto and Fredoka load from Google Fonts. Doto stands in for OffBit and Fredoka for Frankfurter: buy those licences and swap them in `src/template.html`.
- **Scratches:** the scratch texture in `blender/assets/` is Fab "Scratched Polypropylene Plastic".
- **London clip:** check the licence of `site/city.mp4` (the stock clip) before going live.
- **Search engines:** all the channel text is drawn in a canvas, so search engines and social previews see none of it. Before launch add a page title, description, a share image and a hidden text version.
